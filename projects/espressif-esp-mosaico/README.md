# Espressif ESP-Mosaico

ESP32-S31 480 × 480 touch device. This directory owns hardware facts and the
[Corallium factory-firmware derivative](corallium-firmware/README.md).

- [Hardware, power and clock limits](specs/hardware.md)
- The connected ESP32-S31 reports board version 1.2 through eFuse and the factory
  BSP. Physical silkscreen and accessory inventory remain unconfirmed.
- The official factory application is `esp-mosaico/esp-mosaico-claw`; the Vibe
  repository is a development workspace, not the factory application's source.
