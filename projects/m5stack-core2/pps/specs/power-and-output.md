# PPS 供电与输出契约

工程使用 Core2 + Module13.2 PPS + Base Bottom v1.1，保留官方 LVGL 界面并提供串口诊断。
固件只运行于 Core2 ESP32，不更新 PPS STM32、地址、UID 或校准区。
硬件版本须按 [设备资料](../../specs/hardware.md) 区分，不能套用 Codex 的 Bottom2 装配假设。

## 两条电源通路

PPS 接受 DC 9–36V。可调香蕉输出与固定隔离 M-Bus 辅助供电独立：辅助电源约为
5V/200mA，不能把 PPS 可调输出的功率额定值当作 Core2 可用预算。

Core2 设置外部总线输入，关闭向 M-Bus 升压输出和电池充电，亮度为 96/255，
不初始化 IMU/麦克风且未启用无线，以控制辅助电源负担。Base Bottom v1.1 提供
电池/引脚扩展，不把 PPS 原始 DC 转换成主机电源。

在这套低负载配置下，关闭底座电池、移除 USB、只给 PPS 12V DC，已确认可持续运行并冷启动。
该结论来自对应装配的用户实物确认，不是由 USB 连接时的 VBUS 读数推断。
高亮度、无线、大扬声器负载或边运行边充电不在这个结论范围内。

## 输出与 I2C 所有权

PPS 为内部 I2C `0x35`，SDA21/SCL22，100 kHz，模块 ID 为 `0x1041`。
LVGL 任务串行执行 UI、控制台命令和 PPS 访问，不另起并行 I2C 任务，避免设定/回读竞争。

启动保持可调输出关闭。使能要求正确模块 ID、有限 VIN 9–36V、有效设定，且电压至少
低于 VIN 1V；本项目允许 0.5–30V、0.001–5A。电流设定是限流值，不是强制输出电流。
`SET` 先关闭输出再改设定、校验回读，必须单独 `ON` 才使能，避免编辑过程中意外改变带电负载。

| 命令 | 语义 |
| --- | --- |
| `STATUS` | 返回模块、使能、模式、VIN、V/I 设定、V/I 回读、温度和主机电源字段 |
| `SCAN` | 内部 I2C 扫描 |
| `SET volts amps` | 有限值与范围检查、关闭输出、写入并回读设定 |
| `ON/OFF` | 通过统一输出函数控制使能，同步 UI |

回读 `mode=0/1/2` 分别为关闭/CV/CC；主机 `battery_ma` 正值表示充电、负值表示放电。
`vbus_mv` 的物理通路取决于 Core2 PMIC/版本，不能统一解释为 USB 输入。
页面右上角 ON/OFF 为常亮状态，进入页面或状态变化时同步，不通过闪烁表示输出。

## 测量结论与边界

12V 输入、0.1A 限流、香蕉端空载条件下，1/3.3/5/8V 的模块内部电压回读与设定
平均偏差在 6.7mV 内，升降设定可用。此为 PPS 自身读回，不是外部万用表精度验收。
真实负载、CC 限流、满载功率和长期温升未由该空载结果建立。

[test_output.py](../tools/test_output.py) 在显式 `--empty-output` 条件下执行有界空载档位，
输入余量不足则跳过相应档位，最后请求并确认关闭。输出端为空载是执行前提；构建和
只读连接检查不能替代它。
实现依据：[PpsConsole.cpp](../src/PpsConsole.cpp)、[main.cpp](../src/main.cpp)；
电路来源见 [README 官方资料](../README.md#官方资料)。
