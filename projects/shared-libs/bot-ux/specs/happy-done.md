# Happy 与 Done 的视觉语义

Happy 表示“很高兴”，Done 表示“已经完成”，对应固定 Mood 值 4 和 11。
它们是调用方选择的角色语义，不自行证明外部任务完成；例如 Core2 的绿色主机信号
仅能表示 New reply，见 [信号投影](../../../m5stack-core2/bot-ux-codex-core2/specs/agent-signals.md)。

## 状态身份与可组合性

Happy 使用圆滑笑弧眼、暖色面颊、Bounce 与两枚收尖星芒。面颊跟随平滑后的眼组中心，
包含方向、IMU 与过渡位移，保持在脸上而非固定屏幕坐标。

Done 在身体下部显示粗圆角勾号。它在所有显式表情和动作组合下持续存在，位于最大眼形
范围之外，以避免“选了另一表情便失去完成标记”。颜色混合 62% accent 与 38% eye，
在 Mono 和 40 px 画布上仍保留对比；星芒使用原 accent。

Auto 对 Happy 选择 Bounce，对 Done 选择 Sparkle。显式 Animation 替换动作，
显式 Expression 替换表情，但面颊/勾号保留 Mood 身份；poke 的瞬态脸优先，结束后恢复选择。

## 星芒与渲染

两枚四角星由收尖三角形和圆中心构成，在身体左右上方交错缩放并轻微偏转，不穿过眼睛
或勾号。零幅度时静止但可见，reduced motion 将运动缩至 20%，状态标记不消失。
采用现有 M5GFX 图元和固定局部变量，不增加堆分配、帧缓冲或持久粒子状态。

选择独立标记与动作，是为了让状态在减少动态效果时依然可辨识，而不是依赖运动推断情绪。

## 检查依据

原生预览检查 40/72/120/286 px 的 Happy/Done 区分、两枚非圆形星芒、连通勾号、
Night/Mono 对比、零/减少动作下标记，以及九表情×九视线的互不相交。
图示：[286 px](../docs/happy-done-raster.png)、[40/72 px](../docs/happy-done-small-raster.png)。
它们是源码 RGB565 捕获，说明几何和颜色关系，不代替面板、声学或物理交互测量。
