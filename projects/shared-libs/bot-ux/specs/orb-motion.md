# Thinking 与 Working 点阵球

Thinking 用协同呼吸的球壳表达思考，Working 用向上流动并反向旋转的经线点流表达工作。
两者占据与常规身体相近的视觉尺度，并替换身体和眼睛；`bodyColor` 是点色，`bgColor`
是背景，状态标签由宿主绘制。设计参考为 MetalForge 的 Breathe/Vortex 运动语言，
实现使用本项目的原生几何与时序，不依赖 shader。

## 运动与尺度

| 参数 | 当前取值 | 原因 |
| --- | --- | --- |
| 基础周期 | Thinking 1.6 秒；Working 1.4 秒 | 叠加宿主速度与幅度后仍有可辨识运动 |
| 球壳半径 | `0.95R`；身体半径小于 34 px 时 `0.85R` | 匹配主体视觉重量，小尺寸保留边缘余量 |
| 基础点半径 | `max(0.90px,0.030R)` | 避免小点在设备上失去存在感 |
| 点数 | R<34 为 32；R<60 为 64；其余 96 | 按尺寸分配细节和有界成本 |
| Thinking 呼吸幅度 | 0.11 | 纬度延迟的径向膨胀保留整体球感 |
| 深度透明度 | `0.12 + 0.88 × depth^1.35` | 后部可见、前后仍有层次 |

Thinking 的膨胀按纬度错相，并旋转球壳。Working 沿稀疏经线从底部向顶部流动，
在两极淡出和重入、与壳体旋转方向相反；开放通道和环状留白使它区别于 Thinking。

相位系数为 `speed × min(amount,1) × reducedScale`，变形幅度使用 `min(amount,1.5)`；
零幅度冻结点，reduced motion 对相位与变形采用 0.20 系数。
例如 `speed=0.73, amount=0.55` 的完整周期约为 3.99/3.49 秒，这是公式结果而非光学测量。
宿主的腕动开关不应隐式修改 reduced motion。

## 渲染决策

每帧使用固定上限 96 点的栈数组，按深度从后到前绘制，无堆分配或第二帧缓冲。
点是零长度胶囊，距离场边缘与画布实际底像素混合，使重叠点不会产生背景色缝隙。
圆形快速路径省去线段投影；仅在底像素仍是背景时复用内部混色值。

Auto 使用球壳自身动作；显式 Animation 仍可平移整团点阵。边界约束根据点群实际
范围移动整个中心并保留 2 px 余量，不裁剪单点，因单点裁剪会破坏球体结构。
显式 Expression 保留选择，但不能在点阵球上恢复眼睛。
