# 原生 UI、输入与声音组件

组件选择性链接，宿主拥有画布、页面、帧循环和持久化。分开渲染、交互与设备适配，
使同一输入/布局逻辑可由纯主机测试验证，也允许宿主使用不同硬件与页面策略。

## 渲染与字体

`UxRender` 使用 RGB565 覆盖率：圆角实心内部按扫描跨度填充，边界逐像素混色，
空心描边保留内部已有内容。这样保持边缘质量，同时减少大面积逐像素函数调用。
字体是 Noto Sans SC Regular 原生 4-bit 覆盖率，按 Latin14/18/24/28、Clock36、
Cjk18/22/24/28 分开编译；链接器只选宿主实际引用的字体对象。

字集来自真实 Bot 说明和设备 UI，测试扫描消费源文件防止只验证一份手工标签表。
生成字体须保留 OFL、来源校验值与 corpus；原生字号不能以浏览器字体或缩放单色掩码代替。
字体再生成方法见 [README](../README.md)。

## 指针、滚动与键盘

`ScrollModel` 使用连续像素偏移、迟滞和有界惯性，不把滑动量量化成选中行。
拖动一旦成立便不能恢复为点击；释放的重复坐标不能立即抹掉近期速度，停止时间足够长才结束动量。
`PointerSession` 提供捕获目标与手势所有权，具体阈值由宿主配置，不能把 Watch 的 20 px
列表阈值推广为所有组件使用者的固定规则。

键盘限制 16 个英文名字字符，绘制和命中共用矩形，名称持久化与取消属于宿主。
提供中文动作标签但没有中文输入法；字符集能力须与产品承诺一致。

## 声音源与输出适配

`Synth` 是硬件无关源，由样本推进时间；提供 16 个提示音、六种音色、音阶、滑音和包络，
混合限制在 ±15,000。`PcmPlayer` 可选，接受借用的 8-bit 单声道样本，资源无需无条件链接。

M5Output 用三个 2,048 样本缓冲（12,288 字节）和专用发送任务隔离 SDK 等待。
UI 的 `update` 只推进源，发送任务拥有 `playRaw/isPlaying`；SDK 的占用计数不能保证下一次
提交不阻塞，所以禁止 UI 根据计数直接调用播放。正常调度下需至少每 100 ms 更新源。

静音拒绝新提示音并保留音量，已排队音频自然排空；未排队部分使用短释放包络避免截断声。
取消延迟受队列尾部影响，不承诺瞬时静音。暂停硬件需要排空所有借用缓冲并等待 `Speaker.end`
返回，只有 `suspended()` 可作为 MCU 睡眠门槛。设备音量映射由各宿主定义。

生命周期拥有整个 Speaker，可能暂停时不得另有生产者同时使用其 I2S/codec。
对象与借用 PCM 的存储必须覆盖播放和排队生命期，详见 [SOUND.md](../SOUND.md)。
