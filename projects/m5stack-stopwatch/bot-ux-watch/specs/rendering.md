# 渲染、圆屏边缘与刷新成本

界面基于 466×466 RGB565 画布，保持静态内容缓存，按变化区域提交。
此策略减少屏幕传输及重复字体合成，但不把目标刷新间隔视为已测实机帧率。

## 画布与更新边界

| 区域 | 大小/策略 | 原因 |
| --- | --- | --- |
| 完整页面 | 466×466，434,312 字节 | 页面切换与完整合成的标准底图 |
| 表盘 Bot | 286×286，放在 `(90,90)` | 活动帧独立提交，避免重画整屏 |
| 设置 Bot 预览 | 178×178 | 试选状态不影响表盘实例 |
| HUD | 466×90，83,880 字节 | 在画布上合成抗锯齿文字和边缘，无需读回面板 |
| 设置轮播 | 提交 466×280 内容带 | 标题与 Done 缓存，不随图标运动重画 |
| Time/Bot 列表 | 提交 466×264 列表带 | 滚动与固定页面边框分离 |

主体 sprite 在初始化时分配并检查。目标间隔为活动 16 ms、预览 33 ms、变暗 250 ms；
Off 停止绘制。实际帧时需通过 `PERF` 分别观察绘制和传输，不能用抓帧串口速度推算。

## Done 与电池面板共用几何

Done 占据圆屏底部 `y=406..465` 的 60 px 圆弓区域，文字中心为 `(233,432)`。
`doneBounds/doneRowSpan/doneContains` 同时驱动绘制、按下反馈和释放命中，
避免视觉轮廓与点击目标不一致。顶层设置使用克制的文字样式，子菜单和编辑器保留填充弓形。

电池面板在顶端 90 px HUD 内呈门牙形：顶部沿屏幕圆弧，中段 `x=154..312`，
底部圆角收至 `y=71`。三次缓动将偏移从 -72 推至 0，命中随当前动画几何变化。
超过 30% 为绿色 `#42D978`，11–30% 为黄色 `#F2C94C`，0–10% 为红色 `#FF5B57`；
文字、轮廓与量表使用深色 `#101820`。充电增加独立呼吸闪电，不抹掉真实电量颜色。
最后按扫描行裁切，防止文字和闪电泄漏到尚未展开的 HUD 区域。

权威几何是 [WatchControls.h](../include/WatchControls.h) 与
[WatchEdgeGeometry.h](../include/WatchEdgeGeometry.h)，不另建更大的隐形命中矩形。

## 实体键反馈与恢复

A、B、电源键在各自屏幕边缘呈黄色、蓝色、红色液态凸起；按住后约 160 ms 展开，
松开在下一渲染帧清除。各键独立计时，A+B 不共享按压起点。
电源形状的 135° 中心是 UI 定位，不是机械测量值。USB-C 开口没有按键反馈。

A/B 读取 `isPressed()`；电源键通过固定版本 M5Unified 补丁读取 PM1 `0x48` bit0，
读取失败便隐藏反馈，不保留可能错误的按住状态。补丁验证原始/已补丁哈希，拒绝未知版本。
`buttonFx` 关闭立即清除视觉效果，按钮事件仍由输入状态机处理。

27 个覆盖率蒙版离线生成并无损编码，Flash 为 29,969 字节，启动解码至 754,785 字节
PSRAM。选择预计算是为了去除逐帧三角函数，同时保持同一覆盖率几何。
一个 59,840 字节 scratch 区使用 `lgfx::rgb565_t` 维持读写颜色顺序。

标准底图始终无按键覆盖。提交前通过不超过 64 行的 scratch tile 混合反馈，面板不接收
“先干净底图、后覆盖”的中间帧。表盘局部恢复排除 Bot 矩形及已提交 HUD，只刷新剩余区域；
按钮释放、禁用或列表滚动时还需恢复带外的旧反馈区域。这样同时避免闪烁和无效 Bot 拷贝。

## 检查与证据范围

`test_watch_edge_geometry`、`test_ui_controls` 检查边界/命中一致性；
`test_watch_button_feedback`、`test_watch_button_feedback_masks` 和
`test_watch_feedback_patch` 检查蒙版解码、覆盖率、恢复区域及 Bot 不相交。
根目录主机检查重新生成蒙版并逐字节比较提交文件。
原生 renderer 和 `c` 抓取的是画布；真实面板观感、实体键状态及时延须实机确认。
