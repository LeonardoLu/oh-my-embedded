# 输入与交互

本工程以触摸为主、实体键为快捷入口。输入只产生一次明确动作；唤醒、拖动、
取消和点击分别拥有完整的输入序列，避免一次接触同时改变多个状态。

## 接触与手势

- 应用关闭 `M5.Touch` 的轮询，每 8 ms 从 `M5.Display.getTouch()` 采样原始接触。
  `TouchContact` 生成按下、移动、释放边沿，并在释放时保留最后有效坐标。
  这样应用不依赖固定版本 SDK 的 flick/hold 分类及其再次接触识别行为。
- 设置及所有编辑器的控件由 LVGL indev 接收同一校准坐标流。原生滚动容器拥有
  移动/惯性，按钮监听 SHORT_CLICKED，滚动不会再点击原行。粗条 slider 可点击或拖动取值，
  一次接触由滑块或纵向列表独占；列表滚动经过轨道不会接管为改值，滑块接触不会同时滚动列表。
- 选项值使用原生 dropdown；点击展开候选，选择后自动关闭面板并更新当前编辑器草稿，
  不额外确认或退出编辑器。布尔项的整行与右侧 switch 共享一次切换意图，点击开关不重复
  触发行点击。触摸不提供减号/加号；名字使用原生键盘。
- 页面切换和唤醒消费会 reset LVGL 输入设备，避免释放落入新页。
- 表盘静止长按在 3 秒时取消点击资格，不打开个性化。实体键仍保留 2 秒长按阈值。

## 表盘入口

| 输入 | 行为 | 决策原因 |
| --- | --- | --- |
| A | 从全部 14 个情绪中选择与当前不同的随机情绪 | 手动探索不局限于自动轮播的安全子集 |
| B | 下一个情绪；320 ms 内双击则回到自动 Idle | 单击等待双击窗口，避免复位前先执行一次切换 |
| A+B 连续 3 秒 | 打开设置并消费两键释放 | 组合键不泄漏为普通 A/B 动作 |
| 长 B | 在省电策略适用时进入手动变暗 | 手动行为与全局电源设置保持一致 |
| 点击 Bot 身体内/外 | 临时看正面/看向接触方向 | 命中依据真实身体而非整块 sprite；详见 [陪伴行为](companion.md) |
| 从顶部 20 px 内开始下滑 | 显示电池面板 | 保持表盘安静，按需展示电量 |
| 点击当前电池形状 | 关闭面板；无操作 6 秒后自动关闭 | 命中随动画形状移动；面板输入不触发表盘动作 |
| 420 ms 内双击可见时间 | 打开设置 | 单击时间不产生导航；非点击手势清空双击候选 |
| 电源/Home 单击 | 回表盘并取消未保存编辑 | 只关闭 PM1 单击重置，不改变硬件双击关机与下载行为 |

## 返回、取消与唤醒

每个非表盘页面有固定底部圆弧 Done。设置不提供触摸取消按钮，名字键盘也没有关闭键。
菜单 A 打开选中项，B 选中下一项并滚动至可见；编辑器 A/B 保留对当前字段的减少/增加
或前后选项切换。触摸控件选择相应字段并清除实体键导航框。编辑器长 A 取消并恢复快照，
长 B 保存；Home 丢弃未保存草稿并回表盘。下拉选项与滑块松手仅更新草稿，Done 才持久化；
连接窗口仍按其即时操作规则生效。日期/时间字段选择不写 RTC，Done 仍走 [时钟验证](clock.md)。
唤醒边沿只恢复显示，不能同时选情绪、点击设置或执行 Home。应用等待完整释放后
才重新接受控制，并吸收电源键唤醒后同一次按压迟到的 SDK click 事件。
