# 设置与持久化

所有设置页面由 LVGL 8.4.0 原生控件绘制和处理触摸。主状态机仍在 `main.cpp`；
LVGL 发出打开、修改、保存、取消等意图，RTC 校验、NVS 和电源策略保持各自所有权。

## 层级与保存

| 入口 | 内容 |
| --- | --- |
| Time | 时间、日期、12/24 小时与秒显示；无效 RTC 的成对确认见 [时钟](clock.md) |
| Bot | 表情、动作、形状、眼形、HSV、幅度/速度、腕动、名字、语言、视线与 1,120 组合预览 |
| Display | 正常亮度、主题、PM LED、表盘实体键反馈、说明文字与上下布局 |
| Sound | 总开关、启动、按键与提示音 |
| Power | 省电、变暗亮度/延迟、息屏延迟、唤醒方式、充电保持唤醒、强制息屏及起止小时 |
| Connection | 本地蓝牙开关/连接状态/剩余窗口，另有只读协议页；见 [设备通信](connection.md) |

入口与子菜单使用纵向卡片列表，LVGL 负责惯性滚动和点击排他。编辑器使用原生开关和明确的
减号/加号控件；颜色用 Hue、Saturation、Brightness 三条原生 slider，名字使用
原生 textarea/keyboard，最多 16 个 ASCII 字符。底部操作不参与滚动。

菜单 Done 回上级，顶层 Done 保存并回表盘。编辑器 Done 保存，Cancel/长 A 丢弃
编辑器快照；Home 取消草稿后回表盘。连接开关即时生效，连接/协议页只有固定 Done，
返回和 Home 允许窗口继续至超时。时间编辑保留无效 RTC 的日期/时间成对确认和写回错误反馈。

A 在菜单打开选中项，B 顺序选中下一项并让 LVGL 滚动至可见；编辑器 A/B 减少/增加
当前字段，长 B 保存。触摸减号/加号同时选择字段，触摸结束不保留实体键选择框。
双击表盘时间或 A+B 三秒进入设置；Bot 身体长按不打开设置。

## 渲染与预览

[WatchLvgl](../src/WatchLvgl.cpp) 创建 LVGL 对象树，使用固定 466×24 RGB565 draw buffer。
对象在页面切换时重建，未改变的数值不重设 label；不为 Bot 动画逐帧重建对象。
标题、圆角卡片、按下状态、滚动及输入区域由相同控件拥有，避免平行手写命中表。

字体通过 LVGL glyph 回调使用既有 Latin24/Cjk24 的 4-bit 覆盖率数据；HSV 中文标签的
新增字形使用同源、同字号的[项目私有补充字体](../assets/fonts/README.md)。设置 Bot 仍使用
独立的 178×178 BotUx 实例，再作为 LVGL image 缩放呈现；它不覆盖表盘的手动情绪。
颜色与语言等预览即时生效，取消恢复原快照。表盘继续使用既有 M5GFX 区域刷新。
旧 Phosphor 图标与轮播工具保留为已有素材/主机回归资源，不是运行中设置页。

## NVS 与默认值

`watch` Preferences 命名空间及其默认值、键名保持兼容：正常亮度 3/5、变暗 1/5、
15 秒变暗、1 分钟息屏，Sound 及子开关开启，PM LED 关闭，表盘实体键反馈开启。
`wakeMode` 缺失读取 `buttonWake`，`chargeAwake` 缺失可读取 `chargeSave` 的反值。
保存继续写入兼容键。亮度、超时、唤醒、小时独立校验，变暗亮度不得高于正常亮度。
通信时区及事务有效标记在单独 `corallium` 命名空间；本固件不存储 Wi-Fi 配置。

## 验证边界

`tools/check_lvgl.sh` 编译固件同版本的真实 LVGL C 库和 `WatchLvgl.cpp`，测试原生指针点击、
滚动不误触、减号/加号、保存/取消和输入重置，同时输出 native raster。
原有 RTC、NVS、电源、表盘和共享 Bot 主机检查继续有效；旧手绘控件测试不等于 LVGL 测试。
串口 `vNN` 保留页面选择，`contact 1|0 x y` 进入 LVGL 指针路径；`v18/v19` 现为设置入口，
不再展示旧轮播分数位置。主机测试和串口注入均不能替代 CST820B 的真实手指验收。
