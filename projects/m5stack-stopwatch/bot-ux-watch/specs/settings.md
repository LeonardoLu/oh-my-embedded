# 设置与持久化

设置按用户意图分成 Time、Bot、Display、Sound、Power 五个入口。
时间写入 RTC，偏好写入 NVS；外观预览使用独立 Bot 实例，避免试选覆盖表盘状态。

## 层级与保存行为

| 入口 | 内容 |
| --- | --- |
| Time | 时间、日期、12/24 小时与秒显示；无效 RTC 的成对确认见 [时钟](clock.md) |
| Bot | 表情、动作、形状、眼形、HSV 颜色、动作幅度/速度、腕动、名字、语言、视线及 1,120 组合预览 |
| Display | 正常亮度、主题、PM 状态 LED、实体键视觉反馈、说明文字显示、时间/说明上下位置 |
| Sound | 总开关、启动声、按键声、提示/效果声 |
| Power | 省电、变暗亮度/延迟、息屏延迟、唤醒方式、充电保持唤醒、强制息屏及起止小时 |

顶层 Done 保存并回表盘，子菜单 Done 回上级，编辑器 Done 保存至上级。
长 A 和 Home 提供取消路径。Done 始终位于滚动区域之外，几何见 [渲染](rendering.md)。
设置入口来自时间双击或 A+B 组合键；Bot 身体长按只参与视线交互。

Sound 总开关控制所有提示音及扬声器传输。子开关不能绕过总开关：启动声控制 Wake，
按键声覆盖选择、确认、导航与返回，提示/效果声覆盖 poke 和错误提示。
显示非 Active 时音频整体暂停，见 [电源](power.md)。

## 横向入口与纵向列表

顶层每页显示 200×200 RGB565 图标、名称、五个位置点和固定左右箭头，背景为黑色。
图标统一使用 Phosphor Duotone 字形，渐变、高光和光晕在工具侧合成；固件不解析 SVG。

横向位移达到 14 px 后进入翻页，纵向主导且达到 20 px 的移动消费手势。
未达到阈值时原图标/名称目标继续捕获；一旦翻页便不能再点击。释放根据近期速度选择
目标页，缓动到 466 px 的页中心。中途触摸打断吸附后仍恢复原目标，避免无意跳页。
左右箭头选择相邻页；B 在五页间循环，A 打开所选页；位置点不作为打开入口。

Time 与 Bot 使用纵向列表，标签左对齐、值右对齐。预览编辑器下方的 120 px 视口
显示两行，其余通过滚动访问。触摸反馈随释放消失，实体键导航保留选择标记。
布局和命中共用 `WatchControls`，避免显示位置与可点击区域分离。

## 字体与资源选择

普通设置使用 Latin24/Cjk24，标题和重要数值使用 Latin28/Cjk28；英文键盘用
Latin24，中文动作标签用 Cjk22。字体为 Noto Sans SC 原生 4-bit 覆盖率子集，
按目标字号生成，以保持圆屏边缘文字和中文笔画清晰。

五张图标以无损逐行 PackBits 存储，使用固定 200 像素解码行，栈占用 400 字节。
选择预合成 RGB565，是为了保留渐变和边缘质量，同时把运行时成本限定为解码和写入。
不与实时 Bot 预览共用 sprite，因两者更新周期和绘制生命周期不同。

## NVS 与默认值

使用 `watch` Preferences 命名空间。默认正常亮度 3/5、变暗亮度 1/5、15 秒变暗、
1 分钟息屏；Sound 及三个子开关开启，PM 状态 LED 关闭，实体键视觉反馈开启。
亮度、超时、唤醒和小时值独立校验，变暗亮度不能高于正常亮度。

当前持久化兼容规则仍是实现的一部分：`wakeMode` 不存在时读取 `buttonWake`；
`chargeAwake` 不存在时可读取 `chargeSave` 的反值。保存同时写入兼容形式，
使使用这些键的固件能保留用户选择。新增键须满足 NVS 的 15 字符限制。

[Settings.h](../include/Settings.h)、[Settings.cpp](../src/Settings.cpp)、
